Before deciding that reusable packaging has failed, simplify the return process and test it again. First, make the instructions highly visible and consistent: place a short message such as “Bring this container back here” on the packaging, receipts, website, and checkout counter. Use simple diagrams showing where, when, and how customers should return items.

Create one obvious return point, rather than sending customers to different staff members or locations. Clearly label the bin or counter, and train every employee to explain the process in one sentence. If customers receive a deposit or discount, state exactly how it works and apply it automatically whenever possible.

Reduce effort by accepting returns during normal shopping hours and allowing containers from any participating store or location. Consider a receipt, QR code, or app only if it genuinely makes returns easier; avoid requiring customers to download technology for a simple task.

Run a short pilot with revised signage and staff guidance. Ask customers where they expected to return packaging, what confused them, and how long the process took. Track return rates, abandoned containers, and repeated questions. Use this feedback to refine the system before judging the underlying idea. The problem may be poor design—not a lack of customer interest in reusable packaging.
