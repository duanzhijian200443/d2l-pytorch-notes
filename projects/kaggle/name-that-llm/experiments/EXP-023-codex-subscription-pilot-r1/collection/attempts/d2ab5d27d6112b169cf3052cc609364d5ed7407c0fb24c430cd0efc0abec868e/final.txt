You can stay friendly while making the return deadline clear:

“I’m happy to help when I can. The last couple of times, the tool came back later than we agreed, so for future borrowing I need us to set a return time you can commit to. If that timing won’t work, no worries—I’ll just need to keep it here.”

If you lend it again, be specific: “Please bring it back by Sunday at 5.” You can also ask them to check with you before keeping it longer, rather than assuming it’s okay.

If it’s late again, it’s reasonable to say, “I’m not lending out my tools for now, but thanks for understanding.” A warm tone doesn’t require a flexible boundary.
