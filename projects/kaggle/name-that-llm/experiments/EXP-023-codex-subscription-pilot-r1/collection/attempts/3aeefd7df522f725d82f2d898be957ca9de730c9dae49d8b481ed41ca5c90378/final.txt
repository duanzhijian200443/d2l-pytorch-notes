Try **one notebook and a simple index**, rather than a notebook for each project.

- **Use one active notebook.** Put meeting notes, ideas, and project thoughts in date order. No need to reserve sections.
- **Number pages as you go.** Leave the first four pages blank for an index.
- **Label each entry.** Add the date and a short project name or “Personal.”
- **Index only what you’ll want again.** Write entries like “Garden: planting ideas—12, 28.” Skip routine notes.
- **Review for five minutes weekly.** Add missing index entries and mark actionable ideas with a star.

For existing notebooks, label their covers and make a single paper directory of important ideas and their locations. Don’t copy everything over—just start the new system today.
