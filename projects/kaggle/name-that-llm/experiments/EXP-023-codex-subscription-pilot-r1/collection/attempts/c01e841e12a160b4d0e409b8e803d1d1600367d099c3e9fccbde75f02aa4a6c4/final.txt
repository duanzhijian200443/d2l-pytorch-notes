Use a three-pass process:

1. **Set a purpose:** Decide what the prints are for—an album, wall display, gifts, or yearly highlights. This prevents keeping every near-duplicate.
2. **Fast triage:** In each event or month, flag only images that create an immediate emotional reaction. Ignore technical perfection initially.
3. **Compare finalists:** For similar shots, keep the one with the best face expressions, clear subject, useful composition, and strongest story. Limit yourself to one or two per moment.

Then review the selected set together: remove repetitions, balance people/places/details, and include a few imperfect but meaningful photos. Aim for a manageable quota, such as 30–50 prints per year. Print small test copies of uncertain favorites before committing to large formats.
