A password manager stores login credentials in an encrypted vault, so users do not need to memorize a different password for every account. They generally need to remember only one strong master password. The manager can also generate long, unique passwords for each service and automatically fill them in, reducing password reuse and making secure passwords easier to maintain across many accounts. Some managers can store passkeys, security questions, and other sensitive information as well.

However, the user still has important responsibilities. The master password must be strong, memorable, unique, and never shared, because it protects access to the entire vault. Users should also enable multi-factor authentication, keep the password manager and their devices updated, and protect devices from unauthorized access. They must remain alert to phishing: autofill can help, but users should still verify websites and unexpected login requests. Finally, they should keep recovery information or backup codes in a secure place, since forgetting the master password may make the vault impossible to recover.
