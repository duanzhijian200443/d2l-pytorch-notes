A software update that changes a feature modifies what the program does or how users interact with it. For example, it might add a new editing tool, improve search, or change how notifications work. Existing saved files usually remain usable because their structure has not changed.

An update that changes the format of saved files modifies how information is stored, organized, or encoded on disk. This may enable new capabilities or improve efficiency, but it can affect compatibility. Older software may be unable to open files saved in the new format, while newer software may need to convert older files. Such updates often require migration tools, backups, or export options. In short, a feature change affects program behavior; a file-format change affects data compatibility and preservation.
