Let the number of blue buttons be represented by **\(x\)**. Since the jar contains twice as many red buttons as blue ones, the number of red buttons is **\(2x\)**. Together, the buttons total eighteen, so we can write:

\[
x + 2x = 18
\]

Combine the like terms:

\[
3x = 18
\]

Divide both sides by 3:

\[
x = 6
\]

Therefore, there are **6 blue buttons**. The number of red buttons is twice that amount:

\[
2 \times 6 = 12
\]

So, the jar contains **12 red buttons and 6 blue buttons**. To check, add the two counts: \(12 + 6 = 18\), which matches the total. Also, 12 is exactly twice 6, so the ratio and total both satisfy the conditions.
