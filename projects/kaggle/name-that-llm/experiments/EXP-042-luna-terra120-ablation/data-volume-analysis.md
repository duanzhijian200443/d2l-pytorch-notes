# 120条是否太少，以及旧1000条如何理解

2026-11-02，对已完成EXP042作数量、权重与旧数据用途分析。没有训练、追加生成、改写原文或改变原始分组。

**数据量小是合理解释之一，尚未被证明是无收益的原因。** EXP042只测过一个新增规模和一种固定权重，未得到学习曲线；主OOF净少对2条、区间跨0，既不能否定更大同协议样本的作用，也不能推出“加到1000条一定改善”。

## 本轮的增量有多大

每折约2159条官方训练＋10073条公共文本，新120仅相当于旧训练行数约0.98%。沿用同类原公共样本权重后，新120在最终总sample_weight中占约0.478%，两目标类别各增加基线该类总有效权重约4.32%。这些是损失函数样本权重的算术，不是“只学到了0.48%的信息”或预计性能增幅。

新增120对应60个独立题目，不是120个题目。只有Luna/Terra两个标签被新增。它已经使Luna预测数151→161、Terra120→127；目标召回各多对2条，误报也分别增加8/5。说明影响并非完全看不见，但现有对照不能分解覆盖、词表变化、格式分布与类别总权重增加的作用。

## 旧1000与新120的关系

| 数据范围 | 回答数 | 题目数 | 每模型条数 |
|---|---:|---:|---|
| 旧完整采集 | 1000 | 250 | Luna/Terra/Sol/Astra各250 |
| 旧训练部分 | 800 | 200 | 四模型各200 |
| 旧Luna/Terra训练部分 | 400 | 200 | 两模型各200 |
| 新完整采集 | 300 | 75 | 四模型各75 |
| 本次新Luna/Terra训练 | 120 | 60 | 两模型各60 |

旧200条保留回答不能放进训练。新60条保留回答来自旧50个保留题中的15题，两个保留集不是独立的65题。

新120的60个训练题已包含在旧200个训练题里。旧Luna/Terra400中，120条是这些同题的旧协议回答；真正额外题目覆盖为140题、280条。旧800＋新120虽然有920份回答，仍然只有200个训练题组。新旧同题答案必须一起隔离。

## 旧数据的格式差异不能忽略

| 集合 | 换行 | 加粗 |
|---|---:|---:|
| 旧完整1000 | 709/1000，70.9% | 215/1000，21.5% |
| 旧训练800 | 576/800，72.0% | 178/800，22.25% |
| 旧Luna/Terra400 | 270/400，67.5% | 68/400，17.0% |
| 与新120同题的旧120 | 84/120，70.0% | 18/120，15.0% |
| 新Luna/Terra120 | 0 | 0 |

旧协议没有新的单段/无Markdown要求，因此这些差异不是违反旧指令。EXP033未发现明确指令泄露，但其格式和官方输入不同；Stylegram会直接利用字符、词、形状等特征，所以增加旧数据也可能强化来源风格，而非只增加目标模型信息。这是风险解释，未由本轮因果证明。

已有独立只读复算显示，按EXP034/041格式规则筛旧训练800，仅剩208行，四模型72/46/48/42；旧LT400剩118行（Luna72/Terra46），题型也不均衡。直接挑“看起来最干净”的回答会带来模型和题型选择偏差，不能将它们当作等价于新协议采样的数据。若将旧文处理为派生格式视图，需保留原文并单独登记处理规则，不能冒充重新生成。

## 建议的最小后续对照

优先复用已采数据，不因这次小负差就丢弃1000条，也不直接把800或1000一口气加入：

1. 固定同60题、Luna/Terra和新增权重，对比旧120与新120，判断这两批协议/生成条件差异是否影响训练效果。不能把差异全部归因于内置提示。
2. 对比同旧协议的120与400条，使用嵌套题组且保持模型标签、题型选择规则、验证分折和预处理一致。若要检验更多题目覆盖本身，保持每类新增总训练权重一致；若保持每行权重，则数量与总权重一起变，必须这样标记。
3. Sol/Astra属于扩大模型覆盖，另作实验，不能随旧800加入后把效果全部叫作数据量收益。

旧120→400只能回答旧协议的扩量问题。要检验新格式条件下扩到400，需要补齐额外140题×2模型的280条新格式回答，或另设明确的派生格式处理实验，旧回答不能直接替代。当前仅分析，不启动这些实验或采集。
