## 结论需要保留的边界

1. 三组是 **同一 Stylegram 成员的三种公共样本训练权重**，不是三个不同的大模型，也不是完整 ATLAS20 OOF；不能与正式 0.662 榜单分数直接比较。
2. 75% 在每题抽 3 条的稀疏场景均值略高（0.396709 对 0.392327），在抽 2/6 条时低于 50%。这些重复共享训练模型和 prompt，只是场景检查，不足以据此替换设置。
3. 已隔离已知官方 prompt 关联和已知风险标记；未证明穷尽语义重复或上游数据选择偏差。开发折及条件于已拟合模型的 bootstrap 不代表独立重训或隐藏榜单稳定性。
4. 原运行只保存分数、预测、指标和缓存，没有保存拟合后的 SVM 权重。因此可检查聚类/路由/指标一致性，不能不经重训就独立重放中心化模型的全部数值计算。分数是 SVM decision_function，不是校准概率。
