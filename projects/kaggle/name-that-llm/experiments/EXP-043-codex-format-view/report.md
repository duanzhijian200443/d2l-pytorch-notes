## 假设与主要改动

根据用户要求，生成独立的“去换行、去加粗”文本视图。它有可能减轻来源格式差异，但格式也是模型指纹的一部分，是否改善分类需要固定训练对照验证。

规则仅针对这批已经核查的文本：连续CR/LF替换为一个空格，原有其他空格与制表符不变；移除行内代码之外确认成对的`**`加粗分隔符，保留其中正文。两对跨行加粗按同一规则处理。本批没有`__`加粗，不宣称实现通用Markdown渲染。

斜体、代码、标题/列表符号、数字、标点、措辞和单词顺序全部保留。不能把多个单词因删换行而粘连，也不能粗暴删除所有星号。原文不覆盖，源哈希与派生哈希分别记录。

## 运行前核验

原记录SHA固定为`cb903279b3727b31ce2125b89c5ce8f530d769a984f49c2cb86e4fbefb1e9722`，处理前后相同。1000条逐行核对来源text哈希、非格式正文字符、单词序列和二次处理幂等性；编辑范围逐段保留。9项合成测试涵盖跨行加粗、代码中的幂运算、斜体、歧义星号、列表和换行边界。

## 结论、限制与下一步

该版本可用于下一轮有界格式消融。先固定同60题的Luna/Terra120条，比较旧原文与此次去格式版本，保持模型、五折和权重一致，单独识别格式处理是否有收益；之后再研究400条的题目覆盖。不要同时改格式、扩量和权重后把结果归因于其中一项。

去掉表现形式不能还原模型当初的生成过程，也不能证明消除了内置提示影响；列表措辞、回答结构和来源身份限制仍存在。新版是可追溯派生视图，不冒充新协议重采。保留其独立来源/处理标记，暂未合入正式训练池。此次无GPU、API、训练或比赛提交。
