# EXP-052 四模型扩量对照

2026-11-02 北京时间14:43，Kaggle 私有 CPU Notebook 第2版开始运行，15:09确认完成。固定输入、代码及历史对照的字节清单见 [manifest.json](manifest.json)，逐次状态由 [运行记录](../../cloud/stylegram-volume-052/execution-state.json) 保存。

A 使用 EXP042 已验收、不含自采数据的 control 五折预测。B 增加 30 个完整四答题组，共 120 条。C 增加 60 个完整四答题组，共 240 条。B 完全包含在 C 中。10 种题型在 B 中各3题，80/120/160/200 词目标档各9/9/8/4题。C 四档各17/18/16/9题。数据名单与原始回答哈希见 [输入核验](metrics/data-gate.json)。

两臂各用同一份官方 150 题、2,699 条、18 类的五折划分。每臂每折在该折训练文本上拟合词表、IDF 和两种 SVM。原官方行和公共行的权重沿用 EXP042，每条新增回答使用同类原公共行权重。

主比较为 C−B 的合并五折 18 类平衡准确率，同时报告 C−A 和 B−A、逐题组改判、各折差异、四个目标类的召回及误报。按官方原题做 2,000 次配对 bootstrap，seed 42。自采保留集的 15 个题组不进入训练、选样或评分。稀疏场景单列。开发验证集此前已使用，结果解释范围为轻量 Stylegram。
