The size of a light source determines how wide the shadow’s fuzzy region, or penumbra, becomes. A very small, nearly point-like source sends light from almost one direction, so an object blocks it along a well-defined boundary and produces a sharp-edged shadow. A larger source sends rays toward the object from many different points. Near the object, those slightly different shadows still overlap closely, so the edge looks fairly sharp. Farther away, the individual shadows spread apart: some parts of the surface can see only a portion of the source, while others see all or none of it. This creates a broader penumbra and a softer edge. Thus, larger or apparently closer light sources produce fuzzier shadows, whereas smaller or more distant sources produce sharper ones.
