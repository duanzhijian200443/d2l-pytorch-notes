# EXP-021 原创提示词面板

本面板由本次助手于 2026-11-01 直接创作，作为 Codex 订阅来源试采的输入；没有通过额外模型 API 生成提示词，也没有抄取比赛原题或公共池文本。文件为 `prompts.jsonl`，共 250 行英文提示词，供每个选定目标模型回答同一批问题。回答由采集器另行生成，本文件不代表任何模型回答已取得。

## 构成与字段

十类各 25 题：日常建议、科学解释、技术解释（不要求代码）、商业与决策、人文历史、创意短篇、观点权衡、给定原创材料改写、简短邮件、简单推理解释。场景与问题逐条创作，长度要求使用少量固定措辞以保留可记录的控制条件；这些措辞本身也可能改变输出分布。

字段为 `prompt_id`、`prompt`、`category`、`target_words`、`prompt_group`、`split` 和 `source`。来源统一为 `original_codex_authored_20261101`，只表明提示词的创作来源，不表明之后回答的模型身份。

`target_words` 是近似长度提示而非截断标准：80 词 65 题、120 词 100 题、160 词 50 题、200 词 35 题。不应为了满足字数而修改回答原文；超出范围应保留并标记。

## 划分

- `cp0001`–`cp0200` 为 train，十类各 20 题。
- `cp0201`–`cp0250` 为 holdout，十类各 5 题。
- 每题的 `prompt_group` 与其 `prompt_id` 相同；同一题在所有模型、所有调用渠道及所有重复采样中的回答必须继承同一组和划分。
- holdout 只用于独立检查，不得加入训练或用来反复调整提示词。若后续发现两题构成近似改写或共享具体祖先，应合并分组并另建划分版本，而不能继续按现有独立组假设评估。

## 已执行检查

对最终 JSONL 实际读取并验证：250 行均可解析；250 个唯一 ID、分组和规范化提示词；十类各 25 行；前 200 行均为 train、后 50 行均为 holdout；各类 20/5 划分；长度字段只取 80/120/160/200；来源字段一致；提示词均为 ASCII 英文。文件大小 87,764 字节。提示词正文的哈希由根采集任务写入 manifest，不在此重复维护。

## 限制

这是一批新创作候选，不保证与已有公共池没有语义重合。官方 `train.csv` 只有 `id,prompt_id,text,model`，没有原始问题正文，因此本轮未声称完成与官方提示词的精确或语义去重，也未遍历所有公共池做近似匹配。常识解释、日常建议等主题可能与既有数据广泛重叠。

长度分布、主题比例和措辞是本次试采设计，未证明匹配比赛隐藏集。该面板只覆盖英文和有限体裁；模型来源、实际服务版本、推理设置与环境提示词仍由采集清单单独记录。不能因为提示词原创就把由此生成的数据认定为无偏、无泄漏或能提升比赛成绩。
