## 调度与异常处理

计划全局串行，低于原先最多2并发的上限。固定随机种子20261101只决定20个题目×模型单元的顺序；不作为模型sampling seed。每单元按ABBA或BAAB排列两渠道两次重复，平衡先后顺序，减少分渠道整批运行的时间混杂。

接口/网络/限流/鉴权异常、结果未知、模型标识不符、费用缺失、明确截断或无法判断结束状态时，停止所有新调度。不得为了凑齐一个组而继续发请求。无自动重试；所有已返回或失败原件保留，恢复须先检查原始状态。
