# 双渠道重复统计独立复算

从 EXP038 的78条原始索引重新分组、重新计算距离，未从主分析复制任何距离值。完整单元为19个题模单元，10个原题组；另对9个同时具有两模型的完整题组（18单元）复算。源文件SHA-256为`2c560d93f9cce57e42607886cb54449f84e88858a9370d3f175bcf441aea86e7`。

独立实现以token三元组集合对称差/并集计算Jaccard距离；以字符三元组词表构造NumPy向量，点积/范数计算余弦距离；字数差直接按空白切词。每单元取两次同渠道配对的平均、四次跨渠道配对的平均，然后对模型单元在原题内取均值，最后对原题等权。通过整数索引bootstrap重采样整个原题，seed2026110141，20000次，取百分位95%区间；与主分析的值抽样实现数值相符。

统计单位和不确定性处理适合这次探索性面板：同一回答参与多个比较，不应将4个cross距离或总距离对数当独立样本；先汇总题内模型并以原题聚类，避免伪造样本量。整体采用10题等权意味着缺Terra的cp0123只由Luna代表，9题敏感性检查合理地展示缺失覆盖是否改变结论。

只有10个题组、每渠道每单元2次生成，区间不稳定且不是等价性检验。CI跨0只意味着本面板未检出明确超额差异，不能证明没有差异、已经等价或不存在内置提示词影响；没有预先确定的可接受差异阈值，也没有训练收益证据。距离是表面措辞/字符差异，不是语义质量或污染概率。
