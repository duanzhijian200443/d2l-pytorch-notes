## 母版、输入和题组隔离

三臂固定同一母版和环境。0 臂执行作者的 Stylegram 训练代码；120 和 240 臂仅在该成员内增加 EXP052 的已冻结原文。120 臂有 30 个完整四答题组，240 臂有 60 个。保留旧行权重，新增行沿用其类别公共行权重，每折在该折训练文本上重新拟合词表、IDF 和 plain/centred SVM。自采保留题保持隔离。五折及 729 面板的全量拟合共 36 次 Stylegram SVM，另拟合 3 个三臂共享的家族门控。

通过得分版固定的公共加载器，重建公开输入快照为 10,743 条、738 题。历史隐藏任务各附件的字节未全部取得。公共池内有 252 条来自 14 个官方原题的再生回答。五折逐折排除同折验证题的整个再生组，三臂各折排除 36、54、36、72、54 行。全官方数据拟合给面板出预测时保留全部 10,743 行。作者得分时使用 T4 镜像，本次三臂共用相同的固定 CPU 镜像。[输入回执](inputs/input-receipt.json) · [折映射](inputs/regen-fold-map.receipt.json) · [配置及文件清单](manifest.json)

## 决定与成本

保留 0 条作为当前默认。120 条可以保留为候选，其五折优势很小，进入主栈后没有观察到额外改判。当前没有证据支持按此规则扩到 240 条。正式榜单增益未知。

训练使用两个并行的私有 CPU Notebook。共同主 SVC 约 25 分 31 秒，三臂 Stylegram 加共同门控约 50 分 44 秒，时间均不含排队和下载。训练日志、两套源代码、输入绑定和逐行预测保存在项目内。首次发送较大的 Stylegram Notebook 未取得平台版本；核对账户无该任务后，改为挂载原始 CSV，核验与本地同一共享表的 SHA，再成功运行一次。两个成功任务分别是 [共同主 SVC](https://www.kaggle.com/code/zhjianduan/ntl-apex-volume-053-main?scriptVersionId=364792988) 和 [三臂 Stylegram](https://www.kaggle.com/code/zhjianduan/ntl-apex-volume-053-style?scriptVersionId=364793951)。本实验消耗的 GPU 秒数、模型生成额度与比赛正式提交次数均为 0。
