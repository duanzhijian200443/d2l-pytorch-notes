# 完整 ATLAS20 接入检查（只读准备）

本次没有运行完整集成、训练、GPU 或提交。结论来自固定 EXP-004 V2 源码及 EXP-009 谱系投影；机器可核验的路径、行号、哈希和缓存检查范围见 `metrics/integration-readiness.json`。EXP-027 的 17 类 CPU 外部验证是独立的轻量成员实验，不执行本方案。

## 接入位置与不可直接等同的权重

原主流程在 `infer.py:183–231` 拟合 svc4；EXP-009 固定输入投影为 official 2699 + matched 24443 + pool 96686 = 123828 行，样本权重分别为 1/.5/.35，另用 balanced。它的贡献是 `1.5 * log_softmax(d_main_svc4)`。

原 Stylegram 位于 `comp_stack.py:277–307`，plain/centred 按未标记文本推断的组替换行，只加一次 `1.516 * log(clip(softmax(d_style), 1e-9, 1))`。互补栈还经过依赖当前分数的家族 gate，最终 softmax 才以 `.15` 混入主栈。`.1` 是 EXP-024 两个逐行标准化 margin 的内部比例，不是完整集成占比。标准化虽保持单个成员 argmax，alpha=0 也不会保持原完整集成的置信度尺度。

训练配方另有区别：原 Stylegram 投影的公共输入为 10325 行，EXP-010/026 为去除已知再生成祖先后的 10073 行；候选 svc4 为 official2699 + raw/new5400 =8099 行，不能用原主 svc4 的分数替代。投影数字不代表历史隐藏评分时实测行数；部分原附件版本和字节仍未绑定。

## 最小分离对照：缓存重成员一次，重放四个固定臂

先冻结当前完整输入快照、运行环境、成员清单和同一评测批次。原模型字节未完全绑定前，只能称为当前快照对照，不能称为历史 0.662 的精确重现。

| 臂 | Stylegram 主贡献 | 相邻差异的解释 |
|---|---|---|
| A0 | 原 10325 公共行配方的 raw margins | 当前快照的完整基线 |
| A1 | EXP-010 固定 10073 公共行配方的 raw margins | 仅替换 Stylegram 训练配方；包括显式冻结的 solver 参数，不能把它自动解释成纯删行效应 |
| A2 | 与 A1 同一 fitted scores，逐行 z-score | 标准化造成的完整集成尺度变化 |
| A3 | `.9*z(d_style_A1) + .1*z(d_raw_svc4_8099)` | 在相同标准化尺度上加入已固定的小比例 svc4 |

各臂都把该分数按原 `softmax→clip→log×1.516` 放回 Stylegram 位置，其余成员原样保留。A1 只替换 Stylegram 分支，不能全局替换 EXTRA 使家族 gate 的训练数据也跟着变。若需要纯数据删行效应，A0/A1 应另行预定完全相同的 Stylegram 实现、参数和运行环境，并把“历史原配方到统一实现”的差别单列，不能暗中归因给数据。

原主 svc4 在四臂都保持原位、原权重；A3 引入另一个 svc4 配方，存在相关模型证据叠加。不能顺手删掉主 svc4：主栈除数是非零 LP 数组个数，删除还会改变整个主栈温度。A0→A3 是净组合变化，只有相邻对照分别回答配方、标准化和追加成员的效应。不得据面板结果扩展 alpha 或温度网格后宣称独立确认。

## 必须保存和重放的内容

缓存必须绑定 IDs、18 列标签顺序、文本/输入/源码/模型哈希、实际成员激活情况与分组；保存主栈各 LP 和有效成员除数、互补栈 gate 前贡献、原始 gate scores、Stylegram 与候选 svc4 的 raw margins。仅保存经过 gate 的 `comp_logit.npy` 不能安全减旧加新；`--save_lp` 只有汇总且在最终 typography 前，也不足以重放。

按每个臂依次重算 family gate、主/互补混合、ATLAS、Sinkhorn、typography。ATLAS 请求集合由混合后 top2 概率差 `<.3` 决定；先算四臂请求的并集，一次缓存这批 ATLAS 输出，再各自应用原路由。并集没有全部完成时必须报告覆盖不足，不能把预算导致的覆盖变化归因为融合；固定共同覆盖只能称固定覆盖消融。对声明完整的成员缺失、COMP/ATLAS skipped，应停止验收而非默默降级。

固定原 model/tokenizer/adapter/precision/max_len/seed 配置及全部主/互补权重，特别是主 svc4=1.5、tfidf=.25、distort=.10、comp=.15、ATLAS=.20/threshold=.3、sk_div=1、adapt=1/threshold=.15、Sinkhorn=.45/target_mix=.35/100 次、post=0、typography scale=1.5/cap=.30。预测和 Sinkhorn 先验保留 18 类；部分标签外部面板只在计分阶段计算已覆盖标签宏召回，不能用真标签掩掉其他输出列。

## 可复用证据与验证边界

本地检索 `experiments/`、`cloud/`、`reviews/` 的 NPZ/NPY，以及相关执行状态与缓存清单，没有找到可核验的完整集成 OOF 或外部四类面板的全成员缓存。已有轻量 OOF 和 EXP-026 原分数可用于它们对应的样本与配方；新 17 类面板没有这些已拟合模型，仍需授权的三次 CPU refit。旧 V32 记录为三条公开测试样例且任务中断，不能充当外部验证缓存。未查询远端，因此不宣称远端绝对不存在其他文件。

官方干净 OOF 不能复用 ATLAS 全 2699 训练权重、n14b/q25/deb 的公共池后官方拟合权重、Claude final、l24 五折加全量平均、UltraBERT 全五折平均。全量 adapter 的特征上再切 Gaussian/readout 也不能消除上游泄漏。其他权重的训练谱系部分未知；全栈干净 OOF 需要所有成员的对应训练折隔离和逐折预处理，当前缺失。

外部面板仅通过轻量两成员训练输入隔离，并不自动证明它相对于全部现成 checkpoint 独立。完整集成验证前应补全其已知训练暴露审计；已查看过的 EXP-026 面板也不能在设计新集成方法后再次称为首次独立确认。本次最短路径是先完成已授权的固定 17 类轻量验证；完整集成缓存和四臂重放只作为后续可审查方案，不在本轮执行。
