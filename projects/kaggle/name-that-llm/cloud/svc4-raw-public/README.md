## 为什么调整原草案

原 matched+pool 配方的公共部分有121129行，其中104679行尚无本地直接来源的规范化文本匹配证据，且大汇总池有全量官方标签统计驱动的标点清洗。删去已知121条官方题目关联不能撤销上游依赖，因此暂不把原三源配方的五折分数称作可靠隔离验证。

本次取 prvsiyan 数据集固定V6 `passages.csv` 的 `split=new`：5400条原始回答、300题、18类各300条。逐条核验日志请求、响应、文本及身份字段，保留长度36–294词和Markdown差异；不使用clean、passes_funnel或官方类别标点规则筛选。详见 [数据门槛](../../experiments/EXP-014-svc4-raw-w035/metrics/data-gate.json)。

它仍是开发验证：生成长度参考了官方训练集统计，无法独立认证代理服务端权重，也不能保证排除了全部语义题目关联。5400条中5376条已经命中主svc4原数据投影，不是向ATLAS20新增5400条。

## 固定项与解释

- 保留原主svc4四视图特征、缩放、float32和LinearSVC参数；共用实现是 [src/svc4.py](../../src/svc4.py)，与固定源码的AST提取参考做过合成等价测试。
- 每折的EXP-013只用官方训练折拟合词表和IDF。三组公共权重另外共用一套官方训练折+公共原文的特征矩阵，避免把public词表偷偷带进official-only。
- 因此EXP-014对EXP-013的差异包含特征表示与监督训练两方面；EXP-015/016对EXP-014才是相同行集和表示下的权重单变量。
- 固定sklearn1.6.1及其原生balanced类别权重语义；1.8已改变sample_weight与balanced的交互，不能悄悄混用。开始拟合前核验实际依赖，版本不符立即退出。
- prompt-group-v1五折，主指标Balanced Accuracy。事先指定三项配对比较；稀疏场景只作压力检查，不据单个场景事后选择赢家。
- 4组×5折=20个SVM，CPU双线程顺序执行。整个运行共7200秒上限，内部守护工作期限6900秒，RSS上限12GiB；超限终止自己的子进程并保存失败原因，不扩大预算或自动重跑。

## 文件与交接

- `prepare_inputs.py`：固定原文与调用证据核验，不训练。
- `build_payload.py`：容量估算、代码/配置/输入冻结、生成私有输入包与启动器。
- `runner.py`：每折两套特征、四个模型；预测、权重、矩阵指纹、日志原子落盘。
- `guard.py`：唯一CPU子进程、运行期限与内存保护；不分配GPU。
- `registration.json`：四个EXP与目录的关联。配置各自在对应EXP内，共用控制记录在本目录。
- 产物保存逐折/全量OOF决策分数和指标，不保存拟合SVM权重；决策分数不是校准概率。需要最终推理模型时另行确定配置并训练。

只能在确认旧任务终态后处理故障。完成后下载固定保存版本的输出，验证协议/输入/特征隔离/分数/权重/指标，再将各EXP的OOF和指标放回对应目录、更新台账。Kaggle显示COMPLETE或CLI退出0均不能代替结果验收。
